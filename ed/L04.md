## 0. Blink LED
The default LED pin is connected to GPIO ```21```.  
```e.g.```The default main.py in the chip is blinking the LED 0.5s.  
```python
from time import sleep
from machine import Pin

led = Pin(21, Pin.OUT)
while True:
    led.value(0)
    sleep(0.5)
    led.value(1)
    sleep(0.5)
```
```Assessment``` Learn from the code and modify the code to blink the LED 100ms, 1000ms separately by ```sleep_ms``` function.

## 1. Touchpad
GPIO 1-9 all are touchpads.  
```e.g.```In the ```1st``` project, read the touchpad value in the shell of Thonny.  
```python
from time import sleep
from machine import Pin, TouchPad

tp = TouchPad(Pin(2))
while True:
    value = tp.read()
    print(value)
    sleep(0.5)
```
```e.g.```In the ```2nd``` project, control the state of LED by touchpad value.  
```python
from time import sleep
from machine import Pin, TouchPad

led = Pin(21, Pin.OUT)
tp = TouchPad(Pin(2))
while True:
    value = tp.read()
    print(value)
    sleep(0.5)
    if value > 100000: led.value(0)
    else: led.value(1)
```
```Assessment``` Try to control the LED blinking by touchpad value.

## 2. Button
What is the difference between touchpad GPIO and button GPIO? -- ```PULL_UP```  
```python
import time
from machine import Pin

led = Pin(21, Pin.OUT)
btn = Pin(2, Pin.IN, Pin.PULL_UP)
while True:
    led.value(btn.value())
    time.sleep(0.1)
```

## 3. Buzzer
The default buzzer pin is connected to GPIO ```4```.
```e.g.```Let the buzzer beep in 1kHz. Try a different frequency.  
```python
from machine import Pin
from time import sleep

btn = Pin(2, Pin.IN, Pin.PULL_UP)
buzzer = Pin(4, Pin.OUT, drive=Pin.DRIVE_3)

while True:
        buzzer.value(0)
        sleep(0.001)
        buzzer.value(1)
        sleep(0.001)
``` 
```Assessment``` Control the buzzer beep by user button.

## 4. Play  A Tone
```e.g.```Let buzzer play a tone by defining the musical notes and PWM.  
```python
import machine
import time

# Define the frequencies of several musical notes in Hz
C4 = 262
D4 = 294
E4 = 330
F4 = 349
G4 = 392
A4 = 440
B4 = 494

# Create a PWM object representing pin 14 and assign it to the buzzer variable
buzzer = machine.PWM(machine.Pin(4))

# Define a tone function that takes as input a Pin object representing the buzzer, a frequency in Hz, and a duration in milliseconds
def tone(pin, frequency, duration):
    pin.freq(frequency) # Set the frequency
    pin.duty(512) # Set the duty cycle
    time.sleep_ms(duration) # Pause for the duration in milliseconds
    pin.duty(0) # Set the duty cycle to 0 to stop the tone

# Play a sequence of notes with different frequency inputs and durations
tone(buzzer, C4, 250)
time.sleep_ms(500)
tone(buzzer, D4, 250)
time.sleep_ms(500)
tone(buzzer, E4, 250)
time.sleep_ms(500)
tone(buzzer, F4, 250)
time.sleep_ms(500)
tone(buzzer, G4, 250)
time.sleep_ms(500)
tone(buzzer, A4, 250)
time.sleep_ms(500)
tone(buzzer, B4, 250)
```
