## 1. Read the value of the potentiometer
GPIO ```1-9``` can be used as analog inputs.  
![alt text](L05/image.png ':size=400')  
Be sure to use the correct voltage level -- ```3.3V```.  
```python
from machine import Pin, ADC
from time import sleep

pot =ADC(Pin(2))
pot.atten(ADC.ATTN_11DB)
pot.width(ADC.WIDTH_12BIT)

while True:
    pot_value = pot.read()
    print(pot_value)
    sleep(0.1)
```

## 2. Display the value on the OLED
Install ```ssd1306``` package.  
![alt text](L05/image-1.png ':size=400')  
```python
from machine import Pin, ADC, SoftI2C
import ssd1306
import math
from time import sleep

pot =ADC(Pin(2))
pot.atten(ADC.ATTN_11DB)
pot.width(ADC.WIDTH_12BIT)

while True:
    pot_value = pot.read()
    print(pot_value)
    pot_value_string = str(pot_value)
    
    # ESP32S3 Pin assignment
    i2c = SoftI2C(scl=Pin(6), sda=Pin(5))  # Adjust the Pin numbers based on your connections
    oled_width = 128
    oled_height = 64
    oled = ssd1306.SSD1306_I2C(oled_width, oled_height, i2c)

    oled.fill(0)  # Clear the screen
    oled.text("AnalogRead", 10, 15)
    oled.text(pot_value_string, 30, 40)
    oled.show()  # Show the text
    
    sleep(0.1)
```
