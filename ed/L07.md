# UART -- Universal Asynchronous Receiver-Transmitter
 There are two UARTs in ESP32S3 -- UART0 and ```UART1```.  
 UART0 is used for debugging and communication with the host computer. (GPIO1 and GPIO3)  
 UART1 is used for communication with other devices. (```GPIO43``` and ```GPIO44```)

## 1. LED Control by UART0 -- REPL/USB/Shell
```e.g.```Input "Toggle" in shell, the LED will toggle. The communication channel is USB, which is derived from UART0.
```python
from machine import Pin

led = Pin(21, Pin.OUT)
print(str("\nESP32S3 initialization completed!\n")
      + str("Please input some characters,\n")
      + str("select \"Newline\" below and click \"Enter\". \n"))
while True:
    if input() == "Toggle":
        led.value(not led.value())
```

## 2. LED Toggle Remote Control by Shell
Conect Two ESP32S3s -- Master and Slave. Master sends the command to Slave to toggle the LED. <u>The command is input by ```Shell``` of Master.</u>
```python
# Master
from machine import Pin, UART
import time
uart = UART(1, baudrate=9600, tx=43, rx=44)

print(str("\nESP32S3 initialization completed!\n")
      + str("Please input some characters,\n")
      + str("select \"Newline\" below and click \"Enter\". \n"))

while True:
    if input() == "toggle":
        uart.write("toggle") 
    time.sleep(5)
```
```python
# Slave
from machine import Pin, UART
import time
uart = UART(1, baudrate=9600, tx=43, rx=44)
led = Pin(21, Pin.OUT)

while True:
    if uart.any(): 
        data = uart.read() 
        if data == b'toggle':
            led.value(not led.value())
            print(data)
            print(data.decode('utf-8'))
    time.sleep(1)
```

```python
# Slave
from machine import Pin, UART
import time
uart = UART(1, baudrate=9600, tx=43, rx=44)
led = Pin(21, Pin.OUT)

    if uart.any(): 
        data = uart.read() 
        if data == b't':
            led.value(not led.value())
            print(data)
            print(data.decode('utf-8'))
            print(hex(ord(data)))
            print(bin(ord(data)))
```

## 3. Chat Room
Two ESP32S3 boards, A and B, communicate via UART1, with both connected to a PC running Thonny. A can input messages to send via Shell of A and B can view received messages directly in the Shell of B. Vice versa.
```python
import machine
import select
import sys

# Initialize UART1
uart = machine.UART(1, baudrate=9600, tx=machine.Pin(43), rx=machine.Pin(44))

# Create a poll object
poll = select.poll()
# Register the UART and stdin for polling
poll.register(uart, select.POLLIN)
poll.register(sys.stdin, select.POLLIN)

while True:
    # Poll for events
    events = poll.poll(100)  # Poll every 100 ms
    for fd, event in events:
        if fd is uart:
            # Data received from UART
            received_data = uart.read()
            print("Received:" + received_data.decode('utf-8'))
        elif fd is sys.stdin:
            # User input from Thonny shell
            user_input = sys.stdin.readline().strip()
            if user_input:
                uart.write(user_input)
                print("Sent:" + user_input)
```
